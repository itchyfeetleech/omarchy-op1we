# Project Brief

## Goal

Build a native Omarchy plugin that is a 1:1 replacement of the OP1we mouse driver. Matching user controls from the driver & complete with a battery level indicator.

## Intended users

- Primary user: Omarchy Users with a OP1we
- Environment: Omarchy

## Core workflow

1. The user installs the plugin
2. The plugin shows battery status on top bar with a mouse icon (omarchy theme)
3. The user clicks the mouse icon
4. The plugin displays a pop out window for customising mouse controls

## Required features

- Battery level & connection indicator
- Hover for mouse name, Battery Status & Current DPI
- Native omarchy theme'd pop out window for customing dpi, side buttons & all other feautres present in the original Endgamegear driver.

## Completion criteria

The project is complete when:

- It's uploaded to github and submitted to the Plugin Marketplace
- Full 1:1 replacement of the original driver interface.
- Battery indicator & connection status functioning in top bar, respecting omarchy theme
- Design & Presentation are sleek and omarchy themed.

## Out of scope

- Macros
- Any other mouse other than the exact model I have connected to this system.
- Windows or any other linux distro
